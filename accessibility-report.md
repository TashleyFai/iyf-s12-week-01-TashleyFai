# Accessibility Audit Report

## 1. Introduction

This report describes the accessibility audit of my personal website for the IYF Season 12 Week 1 Web Foundations assignment.

## 2. Accessibility Checks

### Images
- Added alternative text to images using the `alt` attribute.

### Headings
- Used headings in a logical order, starting with `h1`.

### Links
- Used descriptive link text for navigation and external websites.

### Language
- Added `lang="en"` to the HTML documents.

### Main Landmark
- Used the `<main>` element to identify the main content of the home page.

## 3. Testing

- Tool: Google Chrome Lighthouse
  
- Page tested: Home page ("index.html")

- Final accessibility score: 100/100

- Test date: October 20, 2026

The latest Lighthouse report showed an accessibility score of 100/100. I did not record a separate score before making fixes, so I have reported the verified final score only. Lighthouse also recommended additional manual accessibility checks. A perfect automated score does not guarantee that every accessibility issue has been identified.

## 4. Conclusion

The home page achieved an accessibility score of 100/100 in Lighthouse. Further manual checks, including keyboard navigation and checking the other pages, can help identify any remaining accessibility issues.
