How I Started

I started learning web development through the IYF Weekend Academy. I am learning how websites are created using HTML, CSS, and JavaScript.

At first, some concepts were difficult to understand. Practising each step helps me improve my skills.

What I Am Learning

HTML helps me structure a webpage. CSS makes the page attractive, while JavaScript adds interactivity. These technologies work together to create websites.

My Goals

My goal is to become a software engineer. I plan to keep practising, complete my assignments, and build projects that demonstrate what I have learned.
